# RecallBox Android beta QA

The current real-device acceptance checklist is maintained at:
[Android Beta Acceptance](../../docs/UX/ANDROID_BETA_ACCEPTANCE.md).

Before testing, pull latest main, apply all product migrations with your private migration-role URL, and rebuild the native Android dev client (OTA JS refresh does not install the Android Share receiver). The 20-screen prototype is [here](../../docs/UX/RecallBox_Interactive_Prototype.html).

Capture screenshots and failures privately; do not commit personal memories, authentication tokens or device data. Passing TypeScript or Kotlin compilation does not mean visual parity or working Auth0.
